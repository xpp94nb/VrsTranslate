# VRS Studio

Windows 赛车讲解视频与中英文字幕工具。此仓库用于发布轻量软件包，暂不包含完整工程源码。

## 下载

[打开最新发行版下载页面](https://github.com/xpp94nb/VrsTranslate/releases/latest)

展开页面下方的 **Assets**，新用户下载 **`VRS_Studio_2.0.13_Lite.zip`**（约 138 MB）。不要下载自动生成的 Source code 压缩包。

## 使用

1. 完整解压到普通可写文件夹，双击 `VRS Studio.exe`。
2. 自行登录 VRS；首次在“设置”检查并下载缺失组件和模型，建议预留至少 12 GB 空间。
3. 按“赛季 → 系列赛 → 周次/赛道 → 赛车/教练”选择讲解。
4. 默认每段视频独立一个文件夹，输出 MP4、中文 SRT 和英文 SRT。

只登录 VRS 即可显示基础赛车图片和赛道路线图。iRacing 登录为可选项，用于同步更完整的高清素材。

## 2.0.13 全年赛事合入 S4、NEC 车型分析修复

NEC 等全年赛事直接显示在同年的 S4 列表中，不再提供单独的“全年赛事”选项。刷新 S4 同时更新全年赛事；它们保留自己的真实赛程、周次和官方会话。2.0.12 的全年赛事筛选自动迁移到 S4，其他筛选继续保留。

例如选择 **2026 S4 → 跑车 → Nurburgring Endurance Championship**。同一赛道重复举办时，选车页仍跟随官方会话校正，避免核实后车型卡片消失。

优势车型分析支持 NEC 的全年官方赛季，按比赛日期与赛道匹配轮次，并读取耐力赛队伍内部的车手圈速和对应 iRating，每辆参赛车只计一条样本。已用真实 NEC 结果完成 12 场抽样并生成 GT3 排名；样本不足的组别会明确说明，每组仅一种车型时跳过。结果仅为速度趋势估计，并非官方 BoP 结论。车型分析需要本人登录 iRacing。

保留此前播放器跳转档位、人声检测、字幕时间、预发布周与下载稳定性修复。播放器可选逐帧、0.5 秒、1 秒、5 秒，左右方向键和按钮跟随所选档位。

内置约 0.9 MB 人声检测文件，无需重下 Whisper / Qwen 大模型。人声检测用于减少赛车声导致的重复字幕，不保证所有音轨都完全无误；已经生成的旧错误字幕需要重新制作才能更正。

## 在线更新

从 **2.0.5** 起，软件启动时会在后台检查此仓库的最新正式版；设置页也有“软件更新”。发现新版后，可查看发行说明，再点击“更新并重启”。当前 2.0.5–2.0.12 用户可直接在软件内升级到 2.0.13，更新包约 1.8 MB。

下载和安装经过发布签名及逐文件校验。更新只替换程序文件，保留登录、模型、收藏、配置、缓存和成品；下载可取消，安装失败恢复旧版。正在制作视频或准备模型时，不会中断任务进行更新。

兼容版本使用小型更新包，无需每次下载完整轻量版。软件更新不需要 GitHub 登录或访问令牌。

### 首次从旧版升级

2.0.4 及更早版本没有在线更新入口，需先手动升级一次：备份原目录后，完整解压轻量版，将程序文件及 engine 中的程序组件合并到原目录，**保留旧 `studio-config.json` 和 `engine/portable-mode.flag`，不删除 `state`、`engine/data`、`engine/models` 或原数据目录**。这些文件决定原登录和模型位置，不要整目录删除后替换。

升级后，后续兼容版本可直接在软件内更新。发行版中的 `Update.zip` 和 `vrs-update.json` 用于软件更新，不是首次安装包。

## 数据与要求

- 原始分享包不含账号、密码、浏览器登录资料、Whisper / Qwen 大模型、收藏或成品，仅附带小型人声检测文件。

- Windows 10/11 x64，需要 .NET Framework 4.8 和 Microsoft Edge WebView2 Runtime。
- 大模型首次下载需要数 GB 网络和磁盘空间；有效的已有模型可复用。
- 仅用于本人有权访问和下载的内容，不绕过网站权限。
- 第三方许可见 `engine/licenses`，人声检测许可见 `engine/tools/whisper-cpu/vad/LICENSE.txt`。

发行版附有 SHA256 校验文件，可核对下载文件的完整性。
