# VRS Studio

Windows 赛车讲解视频与中英文字幕工具。此仓库用于发布轻量软件包，暂不包含完整工程源码。

## 下载

[打开最新发行版下载页面](https://github.com/xpp94nb/VrsTranslate/releases/latest)

展开页面下方的 **Assets**，新用户下载 **`VRS_Studio_2.0.7_Lite.zip`**（约 137 MB）。不要下载自动生成的 Source code 压缩包。

## 使用

1. 完整解压到普通可写文件夹，双击 `VRS Studio.exe`。
2. 自行登录 VRS；首次在“设置”检查并下载缺失组件和模型，建议预留至少 12 GB 空间。
3. 按“赛季 → 系列赛 → 周次/赛道 → 赛车/教练”选择讲解。
4. 默认每段视频独立一个文件夹，输出 MP4、中文 SRT 和英文 SRT。

只登录 VRS 即可显示基础赛车图片和赛道路线图。iRacing 登录为可选项，用于同步更完整的高清素材。

## 在线更新

从 **2.0.5** 起，软件启动时会在后台检查此仓库的最新正式版；设置页也有“软件更新”。发现新版后，可查看发行说明，再点击“更新并重启”。当前 2.0.5 / 2.0.6 用户可直接在软件内升级到 2.0.7。

下载和安装经过发布签名及逐文件校验。更新只替换程序文件，保留登录、模型、收藏、配置、缓存和成品；下载可取消，安装失败恢复旧版。正在制作视频或准备模型时，不会中断任务进行更新。

兼容版本使用小型更新包，无需每次下载完整轻量版。软件更新不需要 GitHub 登录或访问令牌。

### 首次从旧版升级

2.0.4 及更早版本没有在线更新入口，需先手动升级一次：备份原目录后，完整解压轻量版，将程序文件及 engine 中的程序组件合并到原目录，**保留旧 `studio-config.json` 和 `engine/portable-mode.flag`，不删除 `state`、`engine/data`、`engine/models` 或原数据目录**。这些文件决定原登录和模型位置，不要整目录删除后替换。

升级后，后续兼容版本可直接在软件内更新。发行版中的 `Update.zip` 和 `vrs-update.json` 用于软件更新，不是首次安装包。
